# Security-Test-Payload-Suite

A curated collection of payloads used during authorized web application security assessments.

## Categories

- SQL Injection
- Cross-Site Scripting (XSS)
- HTML Injection
- CSV/Formula Injection
- XML External Entity (XXE)
- Local File Inclusion (LFI)
- File Upload Testing
- Input Fuzzing

## Disclaimer

This repository is intended solely for:

- Authorized penetration testing
- Security research
- Bug bounty programs
- Defensive security validation

**Do not use these payloads against systems without explicit authorization.**

## Usage

Before using any payload, identify the application context:

- HTML Context
- Attribute Context
- JavaScript Context
- JSON Context
- URL Context
- XML Context

Using the correct payload for the correct context helps improve testing accuracy and reduces false positives.
